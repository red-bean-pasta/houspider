# AI Assistant Workspace Memory

This directory stores persistent agent knowledge, findings, and interaction history.

## Directory Structure
- **`notebook/`**: Durable technical findings, architectural decisions, and tool quirks (`<topic>.md`).
- **`historybook/`**: User-agent interaction records, task logs (`<action>.md`), and session handoffs (`handoff_<action>.md`).
- **`tmp/`**: Disposable intermediate outputs, command dumps, and scratch buffers.
